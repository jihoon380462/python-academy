## 1. 무엇이고 왜

## 3. 덱 데이터 모양

### 덱 (`vocab/decks/index.js`)

```js
VocabDecks.add({ id: 'base', name: '기초 일반 단어', desc: '…', tpl: ['r'], newPerDay: 10, sample: true });
```

| 칸 | 뜻 |
|---|---|
| `id` | 카드 id 의 첫 칸. **한 번 정하면 바꾸지 않아요**(바꾸면 그 덱의 복습 기록이 끊겨요) |
| `name` · `desc` | 화면에 보이는 이름과 한 줄 설명 |
| `tpl` | 이 덱의 노트가 만드는 카드 종류. `r` 읽기(영어 → 뜻) · `l` 듣기(소리 → 뜻) · `t` 쓰기(뜻 → 철자) |
| `newPerDay` | 하루에 꺼내는 새 카드 수의 기본값(1 ~ 100). 사용자가 설정에서 바꿀 수 있어요 |
| `credit` | 출처 표기. 덱 개요 화면 아래에 보여요(공개 목록을 쓴 덱은 꼭) |
| `sample` | 다 채우지 않았다는 표시. 화면에 「표본 n개」(50개까지) 또는 「채우는 중」 으로 보여요. 다 채우면 지워요 — 기초 덱은 차례표의 수와 같아졌을 때, 다른 덱은 노트가 50개를 넘으면 검사가 지우라고 해요 |

- 노트가 하나도 없는 덱은 화면에 「준비 중」 으로 나와요.

### 노트 (`vocab/decks/<덱>*.js`)

```js
VocabDecks.notes('base', [
  { id: 'allow', w: 'allow', ko: [['v', '허락하다, ~하게 해 주다']], ex: [['This ticket allows you to enter the museum.', '이 표가 있으면 박물관에 들어갈 수 있어요.']], forms: ['allows', 'allowed', 'allowing'], note: 'allow A to B: A가 B할 수 있게 해 주다' },
]);
```

| 칸 | 꼭? | 뜻 |
|---|---|---|
| `id` | ✅ | 노트 id. 영어 소문자 · 숫자 · 하이픈. 덱 안에서 겹치지 않아요. **내보낸 뒤에는 바꾸지 않아요** |
| `w` | ✅ | 카드에 보이는 단어(40자 안) |
| `ko` | ✅ | 뜻 목록 `[[품사, 뜻], …]` 1 ~ 3개 |
| `ex` | ✅ | 예문 목록 `[[영어, 한국어], …]` 1 ~ 2개 |
| `forms` | | 예문에 나오는 다른 모양(복수 · 과거 등). 예문에서 굵게 보여 줘요 |
| `note` | | 쓰임 한 줄(자주 붙는 짝, 헷갈리는 점, 원래 뜻) |
| `say` | | 읽어 줄 글자가 `w` 와 다를 때(기호 · 줄임말). 예: `w: '( )'`, `say: 'parentheses'` |
| `pron` | | 소리 적기. 듣기 덱에서만 써요 |
| `tpl` | | 이 노트만 카드 종류를 달리할 때. 예: `['r', 't']` |
| `rank` | | 이 덱에서 배우는 차례(1부터). 쓰려면 덱의 모든 노트에, 오름차순으로. 기초 덱은 꼭 써요(차례표의 `no`) |

- 품사 코드: `n` 명사 · `v` 동사 · `adj` 형용사 · `adv` 부사 · `prep` 전치사 · `conj` 접속사 · `pron` 대명사 · `det` 한정사 · `aux` 조동사 · `num` 수사 · `int` 감탄사 · `phr` 표현 · `abbr` 줄임말 · `sym` 기호 · `affix` 접사
- 카드 id 는 「덱/노트/종류」 예요. 예: `base/allow/r`. 복습 기록의 열쇠라서 덱 id · 노트 id 를 바꾸면 기록이 끊겨요.
- 덱에서 노트를 지워도 그 카드의 기록은 지워지지 않고 남아요. 같은 id 로 다시 생기면 이어져요.
- 새 카드는 파일을 불러온 순서 · 파일 안에 적힌 순서대로 나와요. `rank` 는 그 순서가 맞는지 검사가 보는 데 써요.
- 표에 없는 칸을 쓰면 검사가 실패해요. 칸을 새로 만들려면 `tools/check_vocab.mjs` 의 `known` 과 이 표를 같이 고쳐요.

### 품질 기준

본보기는 `vocab/decks/base.js` 의 표본 10개예요.

뜻
- 가장 흔한 뜻부터 1 ~ 3개만 적어요. 사전처럼 늘어놓지 않아요.
- 한 칸은 40자 안, 마침표 없이 써요.
- 자리가 비는 곳은 `~` 로 적어요. 예: 「~하게 해 주다」
- 품사가 다른 중요한 뜻은 칸을 나눠요. 예: `result` 는 명사 「결과」 와 동사 「(결과로) 생기다」

예문
- **직접 쓴 문장**이어야 해요. 사전 · 교재 · 다른 단어장에서 옮기지 않아요(저장소가 공개예요).
- 12단어 안팎의 쉬운 문장으로 써요. 단어 말고는 쉬운 낱말만 써요.
- 첫 예문에는 `w` 나 `forms` 의 한 모양이 들어 있어야 해요(검사가 봐요).
- 한국어는 해요체로, 자연스러운 우리말로 써요. 낱말을 하나씩 옮긴 번역은 안 돼요.
- 기초 덱은 일상 문장, 개발 덱은 실제 에러 메시지나 문서에 나올 법한 문장으로 써요.

그 밖
- `note` 는 한 줄만. 자주 붙는 짝(`instead of A: A 대신`)이나 헷갈리는 점을 적어요.
- 기능어(the · of · to 같은 말)도 넣어요. 뜻 칸에는 하는 일을 짧게 적고, 예문으로 보여 줘요. 이미 아는 사용자는 수준 확인(W4)으로 넘겨요.

## 4. 간격 계산 규칙

코어를 고칠 때만 읽어요.

### 지금 규칙 (모두 Anki 기본값과 같은 방향)

| 무엇 | 값 | 어디 |
|---|---|---|
| 알고리즘 | FSRS-6, 기본 매개변수 21개 | `vocab/fsrs.js` |
| 목표 기억률 | 90% | `VocabCore.engine` |
| 새 카드 학습 단계 | 1분 → 10분 | 〃 |
| 틀린 카드 다시 학습 단계 | 10분 | 〃 |
| 간격 흩뜨리기 | 켬(2.5일 이상인 간격만) | 〃 |
| 하루가 바뀌는 때 | 새벽 4시(처음 연 기기의 시간대) | `cfg.tz` · `cfg.roll` |
| 하루 새 카드 | 덱마다(기본값은 덱의 `newPerDay`) | `cfg.newPerDay` |
| 하루 복습 상한 | 덱마다 200장 | `cfg.maxRev` |
| 미리 보여 주기 | 다른 카드가 없으면 20분 안에 돌아올 학습 카드를 바로 | `VocabCore.LEARN_AHEAD` |

네 버튼
- 다시(1): 못 떠올림. 첫 단계로 돌아가요. 복습 카드였으면 「다시 학습」 이 되고 틀린 횟수가 올라요.
- 어려움(2): 첫 단계에서는 첫 두 단계의 평균(6분), 그 뒤 단계에서는 그 단계를 되풀이해요.
- 알맞음(3): 다음 단계로. 단계가 끝나면 복습 카드로 졸업해요.
- 쉬움(4): 바로 복습 카드로 졸업해요.

오늘 볼 카드를 고르는 순서(`VocabCore.pick`)
1. 지금 다시 볼 때가 된 학습 카드
2. 복습 카드와 새 카드를 고르게 섞기(남은 수의 비율대로)
3. 둘 다 없으면 20분 안에 돌아올 학습 카드
4. 그것도 없으면 끝

- 같은 노트의 다른 카드(읽기와 듣기)는 같은 날 겹쳐 내지 않아요.
- 복습 카드는 밀린 날이 오래된 것부터, 같은 날끼리는 날마다 다르게 섞어요.

### 간격 계산기의 출처와 다른 점

- `vocab/fsrs.js` 는 공개 구현 ts-fsrs 5.4.2(MIT)의 소스를 읽고 같은 계산을 옮긴 것이에요. 라이브러리 파일을 그대로 넣지 않았어요.
- 일부러 다르게 한 곳은 셋이에요(파일 머리 주석에도 있어요).
  1. 「어려움」 을 둘째 단계부터 누르면 그 단계를 되풀이해요(Anki 방식). 참조 구현은 늘 6분이에요.
  2. 지난 날 수를 UTC 날짜가 아니라 「새벽 4시에 바뀌는 하루」 로 세요.
  3. 흩뜨리기 씨앗은 「복습 시각(초)_복습 횟수」 예요. 기기가 달라도 같은 값이 나와요.
- 참조 구현과 숫자가 같은지는 6절 W0 로 확인해요.

### 바꿀 때 조심할 것

- **상태는 기록을 처음부터 다시 계산한 값**이에요(5절). 그래서 계산 규칙(매개변수 · 목표 기억률 · 학습 단계 · 하루 경계)을 바꾸면 모든 카드의 지난 기록이 새 규칙으로 다시 계산되고, 다음 복습 날이 한꺼번에 움직여요.
- 규칙을 바꾸려면 `VocabCore.sig` 도 같이 바꿔요. 그래야 기기마다 상태 캐시를 버리고 다시 계산해요.
- 목표 기억률을 사용자가 바꾸게 하려면, 바꾼 날 복습이 몰리지 않게 할 방법을 먼저 정해요. 지금은 화면에 그 설정이 없어요.

## 5. 저장 · 기기 연동

### 조각 둘

| localStorage 열쇠 | 내용 | 기기 연동 · 백업 |
|---|---|---|
| `academy.vocab` | `{ v, mt, resetAt, cfg, log }` | 들어가요 |
| `academy.vocab.cache` | `{ v, sig, recs, extra, sum, stale }` | 안 들어가요(다시 만들 수 있어요) |

- `log`: 카드 id → 사건 문자열
- `mt`: 마지막으로 바뀐 시각(밀리초). 기기 연동이 「올릴 것이 있나」 를 볼 때 써요
- `resetAt`: 기록을 초기화한 시각. 그 전 사건은 합칠 때 버려요
- `cfg`: `{ t 바꾼 시각, tz 시간대(분), roll 하루가 바뀌는 시, newPerDay, maxRev, auto 소리 자동 재생 }`
- `recs`: 카드 id → 상태(기록에서 계산한 값)
- `sum`: 허브 카드가 읽는 요약. 복습 카드의 「하루 번호 → 장 수」 표가 들어 있어서 허브는 날이 바뀌어도 오늘 몫을 셀 수 있어요
- `stale`: 다른 페이지에서 기기 연동이 기록을 받아 합쳤다는 표시. 단어장을 열면 다시 계산하고 지워요

### 사건 문자열

- 사건 하나 = 시각 6글자(36진수, 2026-01-01 UTC 부터 흐른 초) + 종류 1글자 = 7글자
- 종류: `1` 다시 · `2` 어려움 · `3` 알맞음 · `4` 쉬움 · `0` 되돌림(무효) · `s` 아는 단어로 넘김 · `u` 넘김 풀기 · `f` 처음부터 다시
- 한 카드 안에서 시각은 늘 앞 사건보다 뒤예요(시계가 어긋난 기기에서도 순서가 지켜져요).
- 되돌리기는 사건을 지우지 않고 종류를 `0` 으로 바꿔요.

### 합치기

- 두 기기의 기록은 사건의 **합집합**이에요(`Sync.mergeVocab`).
  - 같은 시각의 사건이 양쪽에 있으면 `0`(되돌림)이 이겨요.
  - 초기화 시각보다 앞선 사건은 버려요.
  - 설정은 최근에 바꾼 쪽을 따라요.
- 합치는 차례 · 횟수와 무관하게 같은 결과가 나와요. 그래서 복습 기록이 사라지거나 두 번 세어지지 않아요.
- 단어장은 프로필과 따로 도장(`mt`)을 봐요. 복습만 한 기기의 화면 설정이 「더 최근」 으로 잘못 이기지 않게 하려는 거예요.
- 단어장 페이지는 카드마다 올리지 않아요. 30초 쉬거나 화면을 떠날 때 한 번 올려요.

- NGSL-S 의 721개 중 697개가 NGSL 에도 있어요. 나머지 24개는 숫자 낱말(two · three …)이에요(`node tools/vocab_base_order.mjs` 출력).
- NAWL 1.2 는 957개이고 CC BY-SA 4.0 이에요: [NAWL](https://www.newgeneralservicelist.com/new-academic-word-list)
- 컴퓨터과학 단어 목록 CSAVL 은 핵심 904개 + 보충 702개이고, 둘을 합쳐 전공 글 말뭉치의 19.90%를 덮어요: [CSAVL 소개](https://www.eapfoundation.com/vocab/academic/other/csavl/)
- 듣기는 2,000 ~ 3,000 단어 가족으로 말에 나오는 단어의 95%를 알게 되고, 그 정도면 이해에 충분할 수 있어요: [재현 연구](https://www.cambridge.org/core/journals/language-teaching/article/how-much-vocabulary-is-needed-to-use-english-replication-of-van-zeeland-schmitt-2012-nation-2006-and-cobb-2007/1D217A56A2E0056E67802A6A8360FDDE)
- Anki 설명서: FSRS 는 Anki 23.10 부터 쓸 수 있고 목표 기억률 기본값은 90%예요. 학습 단계의 예는 1분 · 10분이고, 「어려움」 은 첫 단계에서 6분(첫 두 단계의 평균), 그 뒤 단계에서는 그 단계를 되풀이해요. 다른 카드가 없으면 20분 안에 돌아올 학습 카드를 미리 보여 주고, 하루는 새벽 4시에 바뀌어요: [덱 옵션](https://docs.ankiweb.net/manual/deck-options) · [환경 설정](https://docs.ankiweb.net/manual/preferences)
- Anki 설명서의 주의: 못 떠올렸는데 「다시」 대신 「어려움」 을 누르면 FSRS 가 맞힌 것으로 보고 간격을 너무 길게 잡아요. 그래서 덱 목록의 안내 글에 「못 떠올렸으면 다시」 를 적어 두었어요.

알려진 한계
- 허브 카드의 수는 단어장 페이지가 마지막으로 계산한 요약에서 나와요. 다른 페이지에서 기기 연동이 기록을 받은 직후에는 「열면 다시 계산해요」 라고만 보여요.
- 카드를 누를 때마다 기록 전체를 저장해요. 카드가 수천 장이 되어 느려지면 저장을 묶는 방법을 찾아요.
- 시간대는 처음 연 기기의 것을 써요. 다른 시간대로 가도 하루가 바뀌는 때는 그대로예요.
- 읽어 주는 소리는 브라우저 기능이라 기기마다 목소리가 달라요. 소리가 안 나는 브라우저에서는 듣기 카드가 글자로 나와요.
- 「전체 초기화」(사이트 설정)는 단어장 기록을 지우지 않아요. 단어장 기록은 단어장 설정에서 따로 지워요.
