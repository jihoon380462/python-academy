# 사이트 의도 — 무엇이 정상이고 무엇이 버그인가

QA · 새 세션이 먼저 읽는 기준 문서예요. 화면에서 본 것이 의도인지 버그인지 여기서 판단해요.

- 업데이트: 2026-11-12 · v2.46.1 (영어 단어장의 아는 단어 넘기기: 2절 끝) · 2026-11-12 · v2.46.0 (영어 단어장: 2절 끝 · 3절 채점 없음 · 6절 묶음과 카드 · 7절 검사) · 그 전 2026-11-08 · v2.43.1 (읽기 쉽게 다시 씀 · 낡은 값 고침: 알고리즘 모의고사 10문제 · 레슨 36, 8절 예정 코스)
- 처음 쓴 때: 11/6 v2.10.1. QA 가 사이트 의도를 알 수 있게 문서를 최신화하라는 사용자 지시였어요.
- **다른 문서와 다르면 이 파일이 맞아요.** 아래 문서에는 문제집 시절 기록이 섞여 있어요.

## 1. 누구를 위한 사이트인가

- **사용자 본인 한 명**이 쓰는 학습 사이트예요(성인 입문자, D1).
  - 혼자 쓰는 사이트라 억지로 붙잡아 둘 필요가 없다는 게 사용자 생각이에요.
- 목표는 **완강하면 혼자서 만들 수 있게(create)**.
  - 따라 치기 · 반복(repeat)만으로는 혼자 만들 수 없다는 게 사용자 판단이에요(11/6, D7).
- 그래서 **게임 요소(XP · 레벨 · 스트릭 · 뱃지 · 잠금 · 채점)로 붙잡지 않아요.**
  - 읽고, 자기 컴퓨터의 진짜 도구로 만들어 보는 게 중심이에요.
- **실전은 오픈북**(D8): 문법 · 명령을 숨기거나 외우게 하지 않아요. 도감에서 찾아 쓰게 해요.

### 코스별 정상 동작

- 흔들리는 값(pytest 시간 · pandas 칸 너비 · 무작위)은 출력 예에서 빼요.
- 그림은 파일로 만들고 ☐ 로 확인해요.
- AI와 협업의 「AI 답변」 은 교과서가 쓴 예시예요.

**알고리즘**
- 짜임: A0~A20 + 나눈 레슨 A6B · A16B · A18B · A19B(v2.20.0) · 실전 E1~E4 · 보스 AB1~AB5
  - 레슨 번호는 목차 순서대로 0~30.
  - E5 · E6 는 「한 걸음 더」 챕터 끝(v2.22.5).
  - AB4 = 모의고사 10문제(v2.42.1 에 15 → 10).
- 파이썬 엔진(Pyodide)은 **그림 버튼을 누를 때만** 받아요. 누르기 전 `Py.phase = idle`.
- 그림은 **레슨 예제 코드만** 돌려요. 내 코드를 넣는 칸 · 채점은 없어요.
- 함수 문제는 「확인 코드」(print(호출))와 출력 예를 보여 주고, 사용자가 VS Code 에서 맞춰 봐요. 긴 입력은 `input.txt`.

- 그림 모양(v2.19.1 #50 · #51 고친 뒤)
  - deque 는 왼쪽이 앞인 상자 줄
  - 집합은 작은 값부터 상자(「집합 · 순서 없음」)
  - 딕셔너리는 위 = 키 · 아래 = 값 표. 키가 많으면 여러 줄, 화면에 다 안 들어가면 「앞 n개만」
  - 함수 안 변수(A6 `merged` · A16 `c`)가 마지막 프레임에서 「비어 있어요」 인 건 함수가 끝났기 때문이에요.

**영어 단어장** (필수교양, 설계 `specs/vocab.md`) — 교과서가 아니에요(v2.46.0)
- 화면 흐름은 Anki 와 같아요: 덱 목록 → 덱 개요 → 카드 앞면 → 「정답 보기」 → 다시 · 어려움 · 알맞음 · 쉬움.
- 사이트가 채점하지 않아요. 얼마나 잘 떠올랐는지는 사용자가 네 버튼으로 정해요.
- 버튼 위의 글자(`<10분` · `4일`)는 그 버튼을 누르면 카드가 다시 나오는 때예요.
  - 같은 버튼이라도 카드마다 며칠씩 다른 게 정상이에요(간격을 조금 흩뜨려요).
- 새 카드를 다 눌렀을 때 10분이 안 됐어도 학습 카드가 바로 다시 나오는 게 정상이에요(20분 안에 돌아올 카드는 미리 보여 줘요).
- 하루는 새벽 4시에 바뀌어요. 하루 새 카드는 덱마다 한도가 있고, 다 하면 「오늘 할 카드를 다 했어요」 가 나와요.
- 노트가 없는 덱(학술 단어)이 「준비 중」 으로 보이는 게 정상이에요(`check_vocab` 이 이 괄호를 실제 덱과 대조해요). 덱 이름 옆의 「표본 n개」 · 「채우는 중」 표시는 다 채우기 전인 덱(덱 정의에 `sample` 이 있음)에만 나와요. 다 채운 덱에 이 표시가 보이면 버그예요.
- 듣기 덱(v2.46.6)은 카드 앞면에 단어가 없고 「소리 듣기」 단추만 있는 게 정상이에요.
  - 기호 · 식 · 코드 노트(`( )` · `x²` · `elif`)도 듣기 카드 한 장이에요. 소리는 그 기호를 읽는 말(parentheses)로 나오고, 뒷면에 기호가 보여요.
  - 뒷면의 「소리:」 줄은 강세 표시 철자와 한글 소리예요(pa-RAM-e-ter [퍼래미러]). 한글은 외래어 표기가 아니라 미국 영어 소리라서 우리말 외래어와 달라 보이는 게 정상이에요.
- 개발 단어 덱(v2.46.7)은 뜻 칸에 「커밋하다 (바뀐 내용을 한 덩어리로 기록하다)」 처럼 우리말 낱말 뒤에 괄호 풀이가 붙는 게 정상이에요. 우리말 한 낱말로 딱 맞지 않는 말에 쉬운 풀이를 붙였어요(결정 D30).
  - 카드는 읽기 한 장이에요(쓰기 카드는 v2.46.9 에 뺐어요 — 아래 「같은 단어는 한 장」).
  - 다른 덱과 같은 낱말(run 등)은 한 장으로 합쳐 봐요(아래 「같은 단어는 한 장」).
- 같은 단어는 덱이 달라도 카드 한 장인 게 정상이에요(v2.46.9, 결정 D32). 먼저 공부를 시작한 덱의 카드로 나오고, 다른 덱 차례가 오면 건너뛰어요.
  - 그 카드 뒷면에 다른 덱의 뜻 · 예문이 덱 이름 아래 붙는 게 정상이에요. 앞에서 나온 뜻과 똑같은 뜻 줄은 한 번만 보여요.
  - 같은 단어의 듣기 · 쓰기 카드가 따로 나오지 않는 게 정상이에요(노트마다 카드 한 장). 속어 덱은 읽기 카드에서 소리를 자동으로 읽어 줘요.
  - 찾아보기는 단어마다 한 줄이고, 여러 덱에 든 단어에는 「기초 · 개발」 같은 덱 표시가 붙어요. 덱 개요의 카드 수도 같은 단어를 한 장으로 세요.
  - 「전체」 로 공부할 때 카드 위 줄에 덱 이름이 보여요.
- 덱 화면의 「하루 새 카드 n장 · 바꾸기 ›」(v2.46.8)를 누르면 하루 한도 시트가 열려요. 폰에서는 아래에서 올라오고, PC 에서는 가운데 창인 게 정상이에요.
  - 저장 단추가 없는 게 정상이에요. 칩을 누르면 바로, 직접 친 수는 치다 멈추면(0.5초) · Enter · 칸을 벗어날 때 · 창을 닫을 때 저장돼요.
  - 하루 중간에 바꾸면 바로 반영돼요. 오늘 이미 본 새 카드보다 적게 줄이면 오늘은 새 카드가 더 안 나오는 게 정상이에요.
  - 복습 상한은 덱마다 적용되는 값 하나라, 어느 덱 시트에서 바꿔도 모든 덱이 같이 바뀌어요.
  - 「전체」 화면에는 덱마다 칩이 있고, 누르면 그 덱의 시트가 열려요.
- 덱 개요의 「아는 단어 한꺼번에 넘기기」(v2.46.1)는 단어만 20개씩 보여 줘요. 뜻이 안 보이는 게 정상이에요(뜻을 보고 「안다」 고 누르지 않게).
  - 표시하지 않고 넘긴 단어는 「보고 지나간 단어」 로 기억해서, 다음에 들어오면 빼고 이어서 보여 줘요. 그 단어들은 그대로 새 카드로 나와요.
  - 듣기 카드만 있는 덱에는 이 버튼이 없어요.
- 소리는 브라우저의 읽어 주기 기능이에요. 기기마다 목소리가 다르고, 기능이 없는 브라우저에서는 스피커 버튼이 없어요.
- XP · 연속 기록 · 뱃지가 없어요.
- 단어장 설정에 테마 · 글자 크기가 같이 있어요(다른 페이지로 보내지 않으려고).

## 3. 교과서 코스에서 「정상」인 것 (버그로 적지 말 것)

  - 화면: 테마 · 글자 크기 · 고대비 · 애니메이션
  - 찾아보기: 용어집 · 에러 사전. 들어가면 「← 설정으로 돌아가기」
  - 기기 연동
  - 진행 데이터: 백업 · 가져오기 · 오프라인 캐시 · 초기화
- 없는 게 정상: 하루 목표 · 게임 요소 · 효과음 · 선생님 칸 · 키보드 · 진동 · 전제 무시 · 온보딩 다시 보기(v2.9.5 부터 숨김)

### 쪽 넘기기 · 버튼

- 레슨 · 시작하기 쪽에서 키보드 **← 이전 · → 다음**(v2.15.3).

- 검색칸 · 슬라이더에 커서가 있으면 키는 글자 커서만 움직여요.
- 마지막 쪽의 버튼은 **「다음 레슨 →」**(다음 레슨 1쪽, v2.22.3) + 아래 「다음: 레슨 n 「제목」 · ☰ 목차로」.
  - 시작하기 마지막 쪽 → 첫 레슨
  - **코스 마지막 레슨 → 목차**(버튼 글자도 목차)

## 5. 교과서의 짜임 (어디를 보면 되나)

- 첫 화면(코스 홈) = **🛠 시작하기**(설치 · 도구 연결, 처음 한 번) + **📚 도감** 카드 + 챕터별 레슨 목록
- 레슨 = 설명 쪽들(각 쪽 아래 📋 복사되는 예제) + 맨 끝 탭 **「🛠 만들어 보기」**
  - 만들어 보기 = 문장으로 된 문제 · 필요한 문법/명령 · 입력 · 출력 예 · 접힌 예시 답
  - 터미널은 문제마다 **준비 명령**(연습 폴더를 처음 상태로 만듦)과 **확인 명령**이 더 있어요.
- 보스(챕터 끝) = 「만들어 보기: …」. 그 챕터를 묶는 큰 문제 + 🏠 생활형 문제
- 데이터: `courses/<코스>/book.js` (전역 `BOOK`: meta · setup · titles · pages · lessonPages · builtins · tasks)
- 화면: `core/ui-views-book.js` (모든 교과서 코스 공용). 머리 주석에 필드 설명이 있어요.

### 이어서 하기

- 「오늘 뭐 할까」 에 바로 답하는 화면이에요.
- 상자 이름은 **「이어서 하기」**(v2.17.1, 예전 「오늘의 할 일」).
- **▶ 이어서 버튼** = 마지막으로 보던 코스 · 레슨 (`core/hub.js` `render`)
  - 기록이 있으면 「○○ 교과서 이어서 읽기」 → 마지막 레슨(레슨 기록이 없으면 그 코스 목차)
  - 기록이 없으면 「파이썬 교과서부터 시작하기」 → 파이썬 교과서 목차
  - 옛 기록에는 아직 아무것도 안 봤으면 안 읽은 첫 레슨으로 간다고 적혀 있었어요. `core/hub.js` 에서는 확인 못 함.
- 없는 게 정상: 「오늘 n/5 문제 · 복습 n개」 줄 · 레벨 · 연속 기록(v2.19.0 보관) · 「오늘의 도전」

### 카드 · 안내 문구

- 코스 카드 = 📖 읽은 레슨 n/m. 레슨 끝까지 넘기면 읽음이에요.
- 영어 단어장 카드 = 「🗂 단어장 · 오늘 할 카드 n장」 + 새 카드 · 학습 · 복습 수(v2.46.0).
  - 아직 안 열어 봤으면 「아직 시작 전」, 오늘 몫을 끝냈으면 「오늘 할 카드를 다 했어요」.
  - 다른 페이지에서 기기 연동이 기록을 막 받았으면 「열면 오늘 할 카드를 다시 계산해요」 가 정상이에요. 허브는 간격 계산기를 불러오지 않아요.
- 허브는 코스 콘텐츠를 읽지 않고, 각 코스 저장 조각의 「읽은 레슨」 만 세요(v2.19.0).
- 허브는 코스의 book.js 를 읽지 않아요.
  - 카드 문구 · 레슨 수는 `core/config.js` 의 `COURSES`(`book:true`, `lessons`, `bookNote`)에 손으로 적어요.
  - `check_book` 이 레슨 수와 「가상 · 시뮬레이터」 같은 옛 문구를 검사해요.
- 맨 위 안내 문구
  - 「문제집」 대신 「채점·점수·잠금 없이 필요한 곳부터」
  - 교과서 코스 이름은 `COURSES`(`book:true`, `short`)에서 만들어요. 코스를 늘리면 저절로 들어가요.
  - GitHub 교과서는 내 GitHub 계정을 써서 「계정 필요 없음」 이 아니라 **「사이트 가입은 필요 없어요」** 예요.
