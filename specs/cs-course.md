## 1. 한 줄로

**코딩은 하는데 그 아래는 모르는 사람이, 작은 파이썬 코드로 직접 흉내 내며 이해한다.**

- 따라가는 길: 비트 → 회로 → CPU → 메모리 → 운영체제 → 네트워크 → 보안.
- 연습은 파이썬 교과서와 같은 **내 PC 의 VS Code + 파이썬**이에요. Windows 그대로, VM 은 필요 없어요.

## 3. 연습 방법

- 파이썬 교과서와 같아요: 설명 → 예제 복사 → VS Code 에서 실행 → 「만들어 보기」 3~4개.
- 예시 답은 CI 에서 python3 로 실제 실행해 출력 예와 비교해요.
  - `BOOK.check` 없음 = 파이썬 기본 검사 · pre_claims.
- 그림은 브라우저 그림 대신 **본문 `<pre>` 글 그림 + 파이썬으로 흉내**예요(9절).
  - 게이트 진리표 · 장난감 CPU 한 줄씩 · 캐시 적중 표를 코드가 찍어요.
- 네트워크 실습은 **내 컴퓨터 안(localhost)** 에서만 해요. CI 에서도 돼요.
  - 인터넷 명령(`ping` · `nslookup` · `tracert`)은 본문 `<pre>` + ☐.

## 5. 목차 (챕터 6 · 레슨 19 + 만들어 보기 4 = 23)

- 레슨 id: `C0`~`C18`. 만들어 보기: `CB1`~`CB4`.
- 레슨 번호 0~18.
- 「자동」 = check_book 이 python3 로 실제로 돌려 봄. ☐ = 내 화면에서 확인.

### 챕터 0 · 시작

#### C0 · 컴퓨터는 무엇을 하나

1. 입력 → 처리 → 저장 → 출력.
2. 층 그림: 앱 → 파이썬 → 운영체제 → CPU · 메모리 → 회로(이 교과서의 지도).
3. 「모든 건 숫자」 — 이 교과서에서 따라갈 길.

- 🛠 내 컴퓨터 정보 찍기(`platform` · `os.cpu_count`) ☐ · 숫자로 바꾸기 맛보기(`ord`)

### 챕터 1 · 정보를 숫자로

#### C1 · 비트와 바이트 · 2진수 · 16진수

1. 비트 · 바이트 · 2진수 세기.
2. `bin` · `hex` · `int("ff", 16)`.
3. KB · MB · KiB.
4. `bytes` · `bytearray`.

- 🛠 2진수 표 · 용량 바꾸기 · 16진 덤프

#### C2 · 글자를 숫자로: ASCII · 유니코드 · UTF-8

1. ASCII 표 · `ord` · `chr`.
2. 유니코드 코드 포인트 `U+AC00`.
3. UTF-8 은 1~4바이트(`"가".encode()` → `eac080`) — 규칙 표.
4. 깨진 글자(cp949 vs utf-8, 파이썬 교과서 L17B 링크).

- 🛠 바이트 수 세기 · UTF-8 손으로 만들기 · 깨진 글자 되살리기

#### C3 · 음수와 소수

1. 2의 보수(8비트 표 · `int.to_bytes(…, signed=True)`).
2. 부동소수점 — `0.1 + 0.2` · 부호 · 지수 · 가수(`struct.pack`).
3. 그래서 돈은 정수(원) 또는 `decimal`.

- 🛠 2의 보수 바꾸기 · float 비트 보기 · 돈 계산 고치기

#### C4 · 그림과 소리도 숫자

1. 픽셀 · RGB(`#ff8800`).
2. 이미지 크기 계산 · 압축이 필요한 이유.
3. 소리: 샘플링 · 비트 깊이(`wave` 모듈로 1초 삐 소리 만들기 ☐).

- 🛠 색 코드 바꾸기 · 이미지 용량 · 작은 흑백 그림을 글자로 찍기

#### CB1 · 🛠 나만의 인코더

- 글자 → UTF-8 바이트 → 16진 덤프 · 2진 덤프 → 다시 글자.
- 바이트 수 · 글자 수 비교 표. 검사: 자동.

### 챕터 2 · 회로에서 CPU 까지

#### C5 · 논리 게이트

1. AND · OR · NOT · XOR 진리표.
2. 파이썬 함수로 게이트(0/1).
3. NAND 하나로 다 만들기.

- 🛠 진리표 찍기 · NAND 로 XOR

#### C6 · 덧셈기: 게이트로 더하기

1. 반가산기(합 = XOR, 올림 = AND).
2. 전가산기.
3. 4비트 · 8비트 덧셈기를 줄줄이 · 넘침.

- 🛠 반가산기 표 · 8비트 덧셈기 · 뺄셈(2의 보수 + 덧셈기)

#### C7 · CPU 가 명령을 실행하는 법

1. 명령 = 숫자, 프로그램 = 메모리의 숫자들.
2. 가져오기 → 해석 → 실행(fetch · decode · execute) · 프로그램 카운터 · 레지스터.
3. 장난감 CPU(LOAD · ADD · SUB · JMP · JZ · PRINT · HALT)를 파이썬으로 한 줄씩.
4. 진짜 CPU 는 — 어셈블리어 교과서 링크.

- 🛠 명령 하나 더하기 · 1~10 합 프로그램 · 한 줄씩 추적

#### C8 · 메모리 계층과 캐시

1. 레지스터 · 캐시 · RAM · SSD 의 속도 차이(숫자 표 · 「사람 시간」 비유).
2. 지역성(시간 · 공간).
3. 캐시 흉내: 적중 · 실패 세기(작은 LRU 캐시).
4. 2차원 배열을 행 · 열 순서로 돌 때. 파이썬으로 시간 재기는 주의 — 개념만.

- 🛠 캐시 적중률 · 블록 크기 바꿔 보기 · `functools.lru_cache`

#### C9 · 컴파일러와 인터프리터

1. 사람 말 → 기계어 두 길.
2. 파이썬은 바이트코드(`dis.dis`).
3. C 는 미리 기계어(어셈블리어 교과서 링크) · JIT 이름만.
4. 그래서 빠르기가 달라요(`timeit` 맛보기).

- 🛠 `dis` 로 읽기 · 나만의 계산기 인터프리터(`+ - * /` 한 줄)

#### CB2 · 🛠 장난감 CPU 시뮬레이터

- 명령 8개 · 레지스터 4개 · 메모리 32칸.
- 프로그램 목록을 받아 실행하고 매 단계 상태를 찍기.
- 곱하기 프로그램 · 무한 반복 막기(최대 단계). 검사: 자동.

### 챕터 3 · 운영체제 맛보기 (사용자 결정: 2 레슨만)

#### C10 · 운영체제가 하는 일

1. 프로그램들과 하드웨어 사이의 관리자(CPU 나눠 주기 · 메모리 · 파일 · 장치).
2. 프로그램(파일) vs 프로세스(실행 중) — `os.getpid` · 작업 관리자 ☐.
3. 시스템 콜 한 줄 소개 → **운영체제 교과서**.

- 🛠 PID 찍기 · 작업 관리자에서 내 파이썬 찾기 ☐

#### C11 · 여러 프로그램을 번갈아 · 메모리 나눠 주기

1. 시간 나눠 쓰기(라운드 로빈을 파이썬 흉내 3줄 표).
2. 프로그램마다 자기 메모리(주소 공간 그림).
3. 파일 = 이름 붙은 바이트(`os.stat`). 더 알아보기 → **운영체제 교과서** K6 · K10 · K16.

- 🛠 라운드 로빈 표 · 파일 크기와 바이트

### 챕터 4 · 네트워크

#### C12 · 패킷과 계층

1. 데이터를 잘라 보내기(패킷).
2. 4층(링크 · 인터넷 · 전송 · 응용) — 봉투 속 봉투 그림.
3. 머리말 흉내: 파이썬으로 패킷 만들고 풀기(`struct`).

- 🛠 잘라 보내고 다시 합치기 · 머리말 붙이기

#### C13 · IP 주소와 길 찾기

1. IPv4 · IPv6 · `ipaddress` 모듈.
2. 서브넷 `/24` · 공인 · 사설(`192.168.`) · `127.0.0.1`.
3. 라우터는 다음 칸만 알아요(`tracert` ☐).

- 🛠 사설 주소 가려내기 · 같은 네트워크인가 · 주소 개수

#### C14 · DNS: 이름을 주소로

1. 이름 → 주소 전화번호부.
2. 단계(내 PC 캐시 → 공유기 → DNS 서버) · `nslookup` ☐.
3. 흉내: 딕셔너리 + 캐시 + TTL.

- 🛠 작은 DNS 흉내 · TTL 만료

#### C15 · TCP: 빠짐없이 순서대로

1. 연결(3단계 악수) · 순서 번호 · 확인(ACK) · 다시 보내기.
2. UDP 와 차이.
3. 포트.
4. `socket` 으로 localhost 서버 · 클라이언트. 같은 파일 안 스레드로 하니 CI 에서도 돼요.
5. HTTP 는 TCP 위의 글자 → HTTP·API·SDK 교과서.

- 🛠 메아리 서버 · 순서 섞인 조각 맞추기

#### CB3 · 🛠 내 컴퓨터 안의 채팅

- localhost TCP 서버 + 클라이언트 2개, 한 줄씩 주고받기 · 닉네임 · 종료 명령.
- 검사: 자동(스레드로 한 파일) + ☐(두 터미널).

### 챕터 5 · 보안 기초

#### C16 · 해시: 데이터의 지문

1. `hashlib.sha256` · 같으면 같고, 한 글자 바뀌면 완전히 달라요.
2. 되돌릴 수 없음 · 충돌.
3. 쓰임: 파일 확인(다운로드 체크섬) · Git 커밋 id.

- 🛠 파일 지문 · 바뀐 파일 찾기

#### C17 · 암호화: 잠그고 풀기

1. 카이사르 · XOR(같은 열쇠로 잠그고 풀기 = 대칭).
2. 열쇠 나눠 갖기 문제 → 공개키.
3. 작은 수 RSA 흉내(`pow(m, e, n)`) — 원리만.
4. HTTPS 의 자물쇠 = 이것들의 조합(경고 4절).

- 🛠 카이사르 풀기 · XOR 잠금 · 작은 RSA

#### C18 · 비밀번호 저장하기

1. 평문 저장 금지. 해시만으로도 부족해요(같은 비밀번호 = 같은 해시, 사전 공격).
2. 소금(salt) · 느린 해시(`hashlib.scrypt` 또는 `pbkdf2_hmac`).
3. `secrets` 로 진짜 무작위 · 비교는 `hmac.compare_digest`.

- 🛠 소금 친 해시 · 로그인 확인

#### CB4 · 🛠 비밀번호 금고

- 가입 · 로그인 · 비밀번호 바꾸기.
- JSON 파일에 소금 + scrypt 해시만 저장 · 틀린 횟수 제한.
- 검사: 자동(정해진 소금으로 시험).

## 6. 검사

- 파이썬 교과서와 같은 검사예요.
  - 예시 답 · 예제를 python3 로 실제 실행

- `noRun` + `checks` 는 ☐: 작업 관리자 · `nslookup` · 두 터미널.

  - 소금 · 열쇠는 고정값으로 시험해요. 본문에는 「진짜로는 `secrets.token_bytes`」.
  - 소켓은 localhost + 정해진 포트 대신 `0`(빈 포트)으로.

## 7. 시작하기 · 도감 · 허브
