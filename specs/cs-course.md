# CS 교과서 — 설계 (N14 · T1, 2026-11-07 Opus)

> 사용자(11/7): 다음 공용 코스 「1번진행」 = **CS · LLM 기초 둘 다**. 사용자 결정(11/3 · 11/6): 「컴퓨터가 실제로 어떻게 돌아가나」, **운영체제는 맛보기 1~2레슨만**(자세히는 운영체제 교과서). 그 밖의 기술적인 선택은 Claude(9절). 형식은 [`specs/asm-course.md`](asm-course.md) 와 같게.

## 1. 한 줄로

**코딩은 하는데 그 아래는 모르는 사람이, 「비트 → 회로 → CPU → 메모리 → 운영체제 → 네트워크 → 보안」 을 작은 파이썬 코드로 직접 흉내 내며 이해한다.** 연습은 파이썬 교과서와 같은 **내 PC 의 VS Code + 파이썬**(Windows 그대로, VM 필요 없음).

## 2. 다른 교과서와의 경계

| 주제 | 다른 교과서 | **CS 교과서** |
| --- | --- | --- |
| 2진법 · 비트 · 부동소수점 수학 | 수학 공간 `M1_binary` · `M1_float` | 「컴퓨터 안에서 어떻게 저장되나」(바이트 · 인코딩 · 2의 보수 · IEEE 754 모양) — 수학은 링크 |
| 비트 연산 문제 풀이 | 알고리즘 교과서 비트 연산 | 회로(게이트)와 이어서만 |
| 진짜 CPU 명령 · 레지스터 | 어셈블리어 교과서 | 개념과 **장난감 CPU**(파이썬으로 만든 명령 6~8개짜리). 진짜 명령은 링크 |
| 프로세스 · 스케줄링 · 가상 메모리 | 운영체제 교과서 | **맛보기 2레슨**(C10 · C11) + 「더 알아보기 → 운영체제 교과서」 |
| HTTP · API | HTTP·API·SDK 교과서 | 그 **아래**(패킷 · IP · DNS · TCP). HTTP 는 「TCP 위의 글자」 한 줄 + 링크 |
| 파이썬 문법 | 파이썬 교과서 | 다시 안 가르침(`bytes` · `hashlib` · `socket` 같은 모듈 쓰는 법만) |

## 3. 연습 방법

- 파이썬 교과서와 같음: 설명 → 예제 복사 → VS Code 에서 실행 → 「만들어 보기」 3~4개 → 예시 답은 CI 에서 python3 로 실제 실행해 출력 예와 비교(`BOOK.check` 없음 = 파이썬 기본 검사 · pre_claims).
- 그림은 브라우저 그림 대신 **본문 `<pre>` 글 그림 + 파이썬으로 흉내**(게이트 진리표 · 장난감 CPU 한 줄씩 · 캐시 적중 표를 코드가 찍음). 9절.
- 네트워크 실습은 **내 컴퓨터 안(localhost)** 에서만(CI 도 됨). 인터넷 명령(`ping` · `nslookup` · `tracert`)은 본문 `<pre>` + ☐.

## 6. 검사

- 파이썬 교과서와 같은 검사(예시 답 · 예제를 python3 로 실제 실행 · pre_claims · 필요한 문법 링크). `noRun` + `checks` 는 ☐(작업 관리자 · `nslookup` · 두 터미널).
- 무작위 · 시간 · 네트워크가 끼면 출력이 바뀜 → 소금 · 열쇠는 고정값으로 시험(본문에 「진짜로는 `secrets.token_bytes`」), 소켓은 localhost + 정해진 포트 대신 `0`(빈 포트)으로.

## 7. 시작하기 · 도감 · 허브

- 시작하기: **1쪽** 「파이썬 교과서 시작하기 1~3 을 했다면 준비 끝」 + 이 교과서 쓰는 법(예제 복사 → 실행 · 그림은 코드가 찍는 표).
- 도감: 쪽 제목의 코드(`encode` · `struct.pack` · `hashlib.sha256` · `socket` …). builtins 「자주 보는 표」: 2 · 10 · 16진 표, UTF-8 바이트 규칙, 속도 숫자 표, 4층 표.
- 허브 「공용」 칸 카드 「CS」, 글리프 `CS`.
