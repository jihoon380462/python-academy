# 아트 검수·요청팀 지시서 (Opus) — 파이썬 아카데미

읽는 순서: HANDOFF.md → specs/workflow.md(1·7·8절) → IMAGES.md → 이 파일. **배포 권한 없음** — 브랜치 `art/<차수-주제>` → PR. 그림 파일 자체는 ChatGPT(생성기)가 만든다. 이 팀은 **요청서를 쓰고, 납품을 검수하고, 통과한 것만 PR로 올린다.**

## 1. 역할 두 가지

| 역할 | 입력 | 출력 |
| --- | --- | --- |
| **요청** | 코드에 새로 생긴 그림 자리(`UI.img(...)` 호출, `assetUrl(...)`), HANDOFF "다음 후보", 사용자 요청 | IMAGES.md 3절에 **n차 요청** 표: 파일 이름·크기·쓰이는 곳(픽셀)·한국어 설명·영어 프롬프트(공통 베이스 + 항목). 스타일은 2절 완료본과 같은 작가 느낌이어야 한다 |
| **검수** | `assets/img/`에 들어온 납품(ChatGPT 커밋 또는 사용자 첨부) | 통과/반려 판정 + IMAGES.md 2절(완료 표)·검수 메모 갱신, `sw.js` 캐시 목록 갱신(`node tools/stamp.mjs`는 **버전을 바꾸지 않을 때만** — 버전은 Fable), PR |

## 2. 검수 절차 (전부 통과해야 2절로 옮긴다)

1. `python3 tools/img_clean.py --check` — 크기(뱃지 256, 그 외 512, 배너 1200 가로)·RGBA 투명·모서리 투명·여백 ≥ 6%·흰 테두리. 흰 테두리가 있으면 `python3 tools/img_clean.py`(인자 없이)로 정리한 뒤 다시 `--check`.
2. **축소본 대조표**: Pillow로 다크(#0f1117)·라이트(#f4f6fb) 배경에 원본 140px + 실사용 크기(뱃지 48·56, 챕터/영역 32, 코스 48, 보스 56/104) 축소본을 한 장에 붙여 눈으로 본다 — 실사용 크기에서 소재가 식별되는가, 흰 띠가 없는가, 같은 세트(2절)와 한 작가 느낌인가, 글자·브랜드·사람 얼굴이 없는가.
3. **앱 렌더**: Playwright로 `courses/<id>/index.html`을 열어 그 그림이 쓰이는 화면을 캡처(뱃지 화면 `UI.go('badges')`, 지도 `UI.go('home')`, 허브 `index.html`). `img.aimg` 중 `naturalWidth > 0`인 수를 세어 전부 로드됐는지 확인. 다크/라이트 둘 다.
4. 판정: 하나라도 걸리면 **반려** — IMAGES.md 3절의 해당 행에 「반려: 이유」를 적고 프롬프트를 고쳐 재요청. 통과면 2절 표로 옮기고 검수 메모(날짜·장수·확인 항목) 한 줄.
5. PR: `art/<차수>` 브랜치에 `[art] n차 검수: N장 통과, M장 반려` 커밋. **`APP_VERSION`·HANDOFF 상태판은 손대지 않는다**(Fable 릴리스 때 stamp·캐시·버전).

## 3. 요청서 쓰는 규칙

- 자리가 **코드에 이미 있는 것만** 요청한다(IMAGES.md 5절의 자리 목록). 자리가 없는 그림은 4절 "그 뒤"에 적고 Fable 작업으로 남긴다.
- 한 차수 = 20장 이하. 큰 묶음은 A/B/C로 나눠 순서를 적는다(먼저 필요한 것부터).
- 프롬프트는 영어, 공통 베이스(1절 규칙) + 항목 1~2문장. 색은 사이트 팔레트 hex로. "no text, no white halo, transparent background, 8% margin"은 매번.
- 같은 종족·세트 규칙을 명시한다(보스 = 꼬마 괴물 종족, 뱃지 = 둥근 메달, 챕터/영역 장식 = 단일 소재 스티커).
