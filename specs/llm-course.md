## 1. 한 줄로

**LLM 은 「다음 글자 맞히기」 를 아주 크게 한 것.**

- 이걸 **numpy 로 처음부터 직접** 만들며 느껴요.
- 따라가는 길: 글자 세기(바이그램) → 확률 · 손실 → 임베딩 → 경사하강 → 어텐션 → 트랜스포머 한 층.
- 마지막엔 내가 학습시킨 작은 모델이 「그럴듯한」 한국어 문장을 지어내요.

## 3. 연습 방법

- 파이썬 교과서와 같은 **내 PC 의 VS Code + 파이썬 + numpy** 예요.
  - 가상 환경에 `python -m pip install numpy`.
  - 예시 답은 CI 에서 python3 + numpy 로 실제 실행해요.
- **학습 글은 하나**: 교과서가 직접 쓴 짧은 한국어 글 `LLM_TEXT`.
  - book.js 의 상수예요. 약 1,500자, 반복이 많은 생활 문장.
  - 만들어 보기에서 `prep: { name: 'data.txt', text: LLM_TEXT }` 로 같은 파일을 준비해요.
  - 저작권 걱정이 없어요.
- 무작위는 늘 고정해요: `np.random.default_rng(0)` / `random.seed(0)`. 그래서 출력 예가 늘 같아요.
- 학습 반복 수는 CI 에서 몇 초 안에 끝나게 해요(작은 모델).
- PyTorch 는 쓰지 않아요(9절). 마지막 레슨에서 「큰 모델은 같은 걸 PyTorch · GPU 로」 를 개념으로만.

## 5. 목차 (챕터 5 · 레슨 16 + 만들어 보기 4 = 20)

- 레슨 id: `N0`~`N15`(Neural). 만들어 보기: `NB1`~`NB4`.
- 레슨 번호 0~15.
- 「자동」 = check_book 이 python3 + numpy 로 실제로 돌려 봄. ☐ = 내 화면에서 확인.

### 챕터 0 · 시작

#### N0 · LLM 은 다음 글자 맞히기

1. 휴대폰 자동 완성 → 「다음에 올 것 맞히기」 를 아주 크게.
2. 맞히기 = 확률 표 · 뽑기 · 이어 붙이기.
3. 이 교과서에서 만드는 것: 글자 세기 → 배우는 모델 → 어텐션 → 내 작은 언어 모델.

- 🛠 가장 흔한 다음 글자(딕셔너리로 세기)

### 챕터 1 · 숫자 세기 모델

#### N1 · 토큰: 글을 조각으로

1. 글자 · 낱말 · 하위 낱말(BPE).
2. 글자 → 번호(`stoi` · `itos`).
3. BPE 한 단계 손으로(가장 많은 짝 합치기).

- 🛠 어휘 만들기 · 번호로 바꾸고 되돌리기 · BPE 두 단계

#### N2 · 바이그램: 앞 글자만 보고

1. 짝 세기 표(앞 글자 → 다음 글자 횟수).
2. 확률 = 횟수 / 합.
3. 가장 흔한 다음 글자로 이어 쓰기.

- 🛠 짝 세기 · 확률 표 한 줄 · 욕심쟁이 이어 쓰기

#### N3 · 확률에서 뽑기 · 온도

1. 늘 1등만 고르면 같은 말만 반복해요.
2. `random.choices(…, weights=…)` 로 뽑기(seed 고정).
3. 온도: 확률을 날카롭게 · 평평하게(`p ** (1/T)`).

- 🛠 뽑아 쓰기 · 온도 비교

#### N4 · 얼마나 잘 맞히나: 손실

1. 정답 글자에 준 확률 → `-log(p)`.
2. 평균 = 교차 엔트로피 · 퍼플렉서티.
3. 0 확률 문제 → 스무딩(+1).

- 🛠 손실 계산 · 스무딩 비교

#### NB1 · 🛠 내 첫 글 생성기

- `data.txt` 로 바이그램 표 · 온도 있는 뽑기로 100글자 짓기 · 손실 출력. 검사: 자동.

### 챕터 2 · 배우는 모델

#### N5 · numpy 맛보기

1. 설치(4절) · `np.array` · 모양(shape).
2. 원소별 계산 · 행렬 곱 `@`.
3. 소프트맥스(`exp` → 합으로 나누기, 큰 수 빼기).

- 🛠 행렬 곱 · 소프트맥스 · 한 줄 원-핫

#### N6 · 임베딩: 글자를 벡터로

1. 원-핫 → 표에서 줄 꺼내기(`E[idx]`).
2. 비슷한 글자는 비슷한 벡터(코사인 유사도).
3. 임베딩 × 가중치 = 다음 글자 점수(로짓).

- 🛠 줄 꺼내기 · 유사도 · 로짓 → 확률

#### N7 · 학습 = 손실 줄이기: 경사하강

1. 기울기 = 조금 바꾸면 손실이 얼마나 바뀌나(수치로 재기).
2. 반대 방향으로 조금(학습률).
3. 1변수 → 여러 변수 · 손실이 줄어드는 표.

- 🛠 `(w - 3)**2` 줄이기 · 학습률 비교 · 수치 기울기

#### N8 · 신경망 바이그램을 학습시키기

1. 가중치 표 W(어휘 × 어휘) → 소프트맥스 → 교차 엔트로피.
2. 기울기 공식 `probs - onehot`(유도는 한 줄).
3. 반복하며 손실이 세기 모델 손실에 가까워져요.

- 🛠 한 걸음 학습 · 100걸음 손실 표

#### NB2 · 🛠 학습하는 바이그램

- `data.txt` 로 W 를 경사하강으로 학습 → 손실 줄어드는 표 → 세기 모델과 비교 → 글 짓기. 검사: 자동.

### 챕터 3 · 어텐션과 트랜스포머

#### N9 · 앞 글자 여러 개 보기: 문맥

1. 바이그램의 한계(한 글자만 봄).
2. 앞 3글자 임베딩을 이어 붙여 MLP(은닉층 `tanh`).
3. 손으로 미분하는 길(역전파 맛보기 — 작은 2층 망).

- 🛠 문맥 만들기(슬라이딩 창) · 순전파

#### N10 · 어텐션: 어디를 볼지 고르기

1. 평균 내기 → 가중 평균.
2. 점수 = 질문(q) · 열쇠(k) 내적 → 소프트맥스 → 값(v) 가중 합.
3. 앞만 보기(마스크 · `-inf`).

- 🛠 가중 평균 · 마스크 있는 어텐션

#### N11 · 셀프 어텐션 Q · K · V

1. 입력 × Wq · Wk · Wv.
2. `softmax(QKᵀ/√d) V` 모양 따라가기(shape 표).
3. 머리 여러 개(멀티 헤드) 이름만.

- 🛠 모양 맞추기 · 셀프 어텐션 한 번

#### N12 · 트랜스포머 블록 한 층

1. 위치 정보(위치 임베딩 더하기).
2. 어텐션 + 잔차 + 정규화 + MLP.
3. 쌓기 = GPT. 순전파만 numpy 로 끝까지(무작위 가중치 → 다음 글자 확률).

- 🛠 블록 순전파 · 위치 임베딩

#### NB3 · 🛠 미니 트랜스포머 순전파

- 정해진 작은 가중치(seed)로 문장 하나를 넣어, 각 자리의 다음 글자 확률 상위 3개를 출력.
- 마스크가 미래를 못 보는지 확인. 검사: 자동.

### 챕터 4 · 내 작은 언어 모델

#### N13 · 학습 고리 만들기

1. 데이터 나누기(학습 · 검증) · 배치.
2. 순전파 → 손실 → 역전파 → 갱신 → 반복. 검증 손실로 외우기(과적합) 보기.
3. 학습률 · 반복 수 · 크기.

- 🛠 배치 뽑기 · 학습/검증 손실 표

#### N14 · 문맥 MLP 언어 모델 학습

1. 앞 3글자 → 임베딩 → 은닉층 → 다음 글자(N9 를 학습까지).
2. 역전파를 numpy 로 손수(층마다 한 줄씩).
3. 바이그램보다 손실이 낮아지는지.

- 🛠 기울기 검사(수치 vs 손계산) · 학습

#### N15 · 큰 LLM 은 이걸 얼마나 크게

1. 크기(매개변수 · 데이터 · 계산) 표.
2. 사전학습 → 미세조정 → 사람 피드백(RLHF).
3. 잘하는 것 · 못하는 것(지어내기 · 최신 정보)을 「다음 글자 맞히기」 로 설명.
4. PyTorch · GPU 는 같은 계산을 빨리 · 크게.

- 🛠 ☐ 내 모델과 큰 모델 비교 글 · 매개변수 수 세기

#### NB4 · 🛠 내 작은 언어 모델

- `data.txt` 로 문맥 MLP 를 학습(정해진 seed · 반복).
- 학습/검증 손실 → 온도 두 개로 문장 짓기 → 세기 모델과 비교.
- 목표: 작은 모델이 어떤 느낌으로 움직이는지 보기. 검사: 자동.

## 6. 검사

- 파이썬 기본 검사: 예시 답 · 예제를 python3 로 실행, pre_claims. CI 의 check_book 단계에 `pip install numpy`.
- 출력은 seed 고정 + 소수 자리 `round(…, 3)` / `f"{x:.3f}"`. numpy 버전 · CPU 에 따라 마지막 자리가 흔들리지 않게요.
- 학습 결과 글은 seed 와 반복 수가 같으면 같아요. 검사 통과 확인 필수.
- 실행 시간: 예제 · 예시 답 하나가 5초를 넘지 않게. 작은 어휘 · 작은 차원 · 반복 수로 조절해요.

## 7. 시작하기 · 도감 · 허브

- **시작하기 2쪽**:
  1. 준비물 — 파이썬 교과서 시작하기 · 가상 환경 · `pip install numpy`.
  2. 학습 글 `data.txt` — LLM_TEXT 를 보여 주고 저장하게. 모든 만들어 보기가 같은 파일을 써요.
- **도감**: 쪽 제목 코드(`np.exp` · `@` · `softmax` · `random.choices` …).
  - builtins 「자주 보는 식」: 소프트맥스 · 교차 엔트로피 · 경사하강 한 줄 · 어텐션 식 · 모양 표.
- **허브**:
  - 처음 계획: 「공용」 칸 카드 「LLM 기초」, 글리프 `AI`.
  - 지금은 📊 데이터와 AI 묶음(지금 상태 표).

## 9. 정한 것과 이유 (기술적 선택 — Claude)

| 무엇 | 정한 것 | 이유 |
| --- | --- | --- |
| id | 코스 `llm`, 레슨 `N0`~`N15` · `NB1`~`NB4` | 다른 코스 글자와 안 겹침 |
| 도구 | 파이썬 + numpy, **PyTorch 안 씀** | numpy 만으로 속이 다 보이게(사용자 결정 — 어떤 느낌으로 움직이는지까지). CI 에 torch(수백 MB)를 깔지 않아도 예시 답을 진짜로 돌림 |
| 마지막 모델 | 앞 3글자 문맥 MLP(학습까지) + 트랜스포머는 순전파까지 | 아래 목록 |
| 글자 단위 | 한국어 음절 하나 = 토큰 하나(BPE 는 N1 에서 맛보기) | 어휘가 작고(학습 글에서 수백 개) 결과를 눈으로 읽기 쉬움 |
| 학습 글 | 교과서가 직접 쓴 짧은 한국어 글 하나(`LLM_TEXT`) | 저작권 없음. 모든 레슨이 같은 글이라 결과를 비교하기 쉬움 |

마지막 모델을 이렇게 정한 이유:

- 트랜스포머 역전파를 numpy 로 손수 쓰면 초보에게 너무 길어요.
- 학습 원리는 MLP 로 끝까지 보여 줘요.
- 트랜스포머 구조는 순전파로 「어디를 보나」 까지 보여 줘요.
- 큰 모델은 같은 고리를 자동 미분으로 돌려요.
