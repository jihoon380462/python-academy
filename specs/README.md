# specs — 지시서 보관함

설계 문서와 지시서를 두는 폴더예요. 아래 표는 이 폴더의 문서를 빠짐없이 적은 목록이에요.

- 무엇을 먼저 읽을지는 [`CLAUDE.md`](../CLAUDE.md) 가 방에 따라 알려 줘요. 문서마다의 쓰임은 [`HANDOFF.md`](../HANDOFF.md) 7절 「문서 지도」 에도 있어요.
- 문서를 더하거나 지우면 이 표를 같이 고쳐요. `node tools/validate_content.mjs` 가 이 폴더의 `.md` 파일과 이 표를 대조해요(LESSON.md R15).
- 자세한 상태는 문서마다 맨 위 「지금 상태」 에 있어요. 여기에는 갈래와 한 줄 설명만 적어요(상태를 두 곳에 적으면 한쪽이 낡아요).
- 이력: 처음에는 기획 채팅이 쓴 지시서를 두고 `docs/EXPANSION.md` 에 편입하던 곳이었어요(11/2 ~ 11/6). 11/15 에 지금 문서에 맞춰 다시 썼어요.
