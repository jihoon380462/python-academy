# 웹 교과서 — 다시 설계 (HTTP·API·SDK 를 따로 뺀 뒤, 2026-11-07 Opus)

> 사용자(11/7): 「코스 마지막에 있는 웹-HTTP-API 의 경우 **웹은 따로 빼서** 할 거고 **HTTP-API-SDK 는 서로 연결되니까 같이 묶을** 거야. 각각 레슨 설계해」.
> 지금 웹 교과서(v2.14.0, `courses/web/`)는 챕터 1 화면 만들기 · 챕터 2 움직이게 · **챕터 3 서버와 대화**(레슨 10 HTTP · 11 fetch · 12 requests · 13 REST·배포 + 만들어 보기 카페 주문 화면)예요. 챕터 3 의 HTTP·API 부분은 새 교과서 [`specs/http-api-course.md`](http-api-course.md) 로 옮기고, 웹 교과서는 **화면(HTML · CSS · JavaScript)만** 다뤄요.
> 이 문서는 **설계**예요. 만들 때 이 문서를 따르고, 바뀌는 건 여기를 먼저 고쳐요. 형식은 `specs/os-course.md` 와 같게. 기술적인 선택은 Claude 가 정했고(HANDOFF 3절 「기술적인 설계 선택은 묻지 말고」) 이유를 9절에 적었어요.

## 1. 한 줄로

**VS Code 와 브라우저로 「보이고 움직이는 화면」 을 처음부터 끝까지 만들기.** HTML 로 뼈대, CSS 로 모양, JavaScript 로 움직임과 상태, 마지막에는 폼 검사 · 접근성 · 파일 나누기 · 고치기(F12) · 배포까지. 서버와 대화하는 원리(HTTP · API)는 HTTP·API·SDK 교과서가 맡아요.

## 2. 다른 교과서와의 경계

| 주제 | **웹 교과서** | HTTP·API·SDK 교과서(새로) | 다른 교과서 |
| --- | --- | --- | --- |
| HTML · CSS · flexbox · 반응형 · JS · DOM · 상태 · localStorage | ✅ 여기가 기준(레슨 0~9 그대로) | 다시 안 가르침 — 필요하면 링크 | — |
| `async` · `await` · `Promise` (JS 문법) · `fetch` 로 **같은 폴더의 JSON 파일** 읽기 | ✅ 레슨 10(언어 기능으로) | `fetch` 로 **진짜 API** 부르기 · 요청/응답 · 상태 코드 · CORS 는 여기 | — |
| HTTP · 상태 코드 · 헤더 · REST · API 키 · `requests` · 서버 만들기 · SDK | 안 다룸(레슨 10 끝에 「더 알아보기 → HTTP·API·SDK」) | ✅ 여기가 기준 | — |
| GitHub Pages 배포 | 레슨 13 에서 **내 화면을 올리는 순서만**(설정 화면은 링크) | — | ✅ GitHub 교과서 G12 가 기준 |
| 파이썬 | 안 씀(웹 교과서는 JS 만) | ✅ `requests` · FastAPI · SDK | 파이썬 교과서 |

## 3. 연습 방법 (지금과 같음)

- **VS Code + Live Server 확장 + 크롬/엣지(F12)**. 공부 폴더 `web-study`, 파일 이름 `lesson10_1.html` 모양.
- 만들어 보기는 「브라우저에서 확인할 것」 ☐ 목록 + 예시 답(파일 전체) — `tools/run_web_solutions.py` 가 예시 답을 미리보기에 넣어 ☐ 를 자동으로 확인(지금처럼).
- 레슨 12(모듈)는 `<script type="module">` 이 `file://` 로는 안 돌아서 **Live Server 필수** — 「먼저 꼭」 경고.
