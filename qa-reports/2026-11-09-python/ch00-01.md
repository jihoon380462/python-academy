- 급상승은 L4(조건문)예요. 설명 쪽은 한 쪽 한 개념이라 완만한데, 만들어 보기에서 올라가요: 정답 줄 평균 2.5 → 6.2(2.5배) · 최대 3 → 8(2.7배), 최장 예제 4 → 7줄, 본문 1070 → 1951자. L4#1 이 첫 문제부터 5줄이고(if/else + input + int + >=), #3~#6 은 4~8줄에 출력 예측 · 고치기가 섞여요.
- L2 는 L4 앞까지는 본문이 가장 길고(1661자 · 8쪽 · 개념 아홉 개)지만 쪽을 잘게 나눠 ↑ 로 봤어요. L3 은 챕터 최소(808자 · 정답 평균 1.3줄)로 숨 고르기 구간이에요.
- L3B 는 새 호출 4개(input · int · float · str)와 「input 은 늘 글자」 라는 형 개념이 처음 나와 ↑ 예요. 그중 L3B/1 한 쪽에 몰린 설명이 챕터에서 가장 빡빡한 설명 쪽이에요(F7).
- B1 은 L4 와 비슷한 길이(평균 7.2줄)에 L1~L4 를 두루 써서 ↑ 완만이에요. 새 문법은 없어요.
- 첫 레슨(L0)에서 급상승은 없어요(1줄 · 3줄 예제). 첫 문턱은 레슨이 아니라 SETUP 의 설치 · VS Code 연결이에요(Q4).
## 사용자에게 물어볼 것
- Q1 · 상황: 「필요한 문법」 칩의 예가 문제의 값 그대로여서 사실상 답이 보여요. 예: L1#2 칩 = `print("나는")` / `print("파이썬을 배워요")`(답과 같음), L3#1 칩 `12 * 34` · L3#2 `2 ** 10` · L3#3 `17 // 5` / `17 % 5`(모두 답), L4#5 `age >= 13 and age <= 19` · L4#6 `guess == secret`(답의 핵심 식). 실전 오픈북 방침(문법을 숨기지 않음)이면 의도일 수 있어요. 선택지: ① 그대로 둠(오픈북 · 따라 쳐도 괜찮음) ② 칩은 문법 모양만 보이고 값은 문제와 다르게(`print("사과")` 처럼) ③ 처음 레슨(L1~L3)만 그대로, 뒤 레슨부터 바꿈
- Q2 · 상황: L0/0 · L0/1 · L0/2 는 풀이용 코드 상자와 바로 아래 「예제 코드」(복사 · 한 줄씩 보기) 상자의 내용이 글자까지 똑같아서 같은 코드가 연달아 두 번 나와요(L1 부터는 앞 상자에 `# 결과` 주석이 있어 달라 보여요). 의도인지 확신이 안 서요. 선택지: ① 그대로(앞은 설명용, 뒤는 실행용) ② 앞 상자에 `# 결과` 주석을 넣어 L1 처럼 구분 ③ L0 은 앞 상자를 뺌
- Q3 · 상황: L2/3(재대입)에 VS Code 디버거(중단점 · F5 · F10 · 변수 칸) 번호 목록 3개가 들어 있어요. 레슨 2 의 개념 쪽에 새 도구 4가지가 한꺼번에 나와 초보 성인에게 급한지, 선택 읽을거리로 충분한지 확신이 안 서요. 선택지: ① 그대로 ② 「해 보면 좋아요(선택)」 표시를 달아 접음 · 작게 ③ 디버깅 사고법(레슨 47) 쪽으로 옮기고 여기서는 한 줄 소개만
- Q4 · 상황: 시작하기(SETUP)는 4쪽 · 상자 18개 · 약 4547자로 첫 레슨보다 훨씬 길고, 프로그래밍을 처음 하는 사람에게 PATH · 확장 · 인터프리터 · 터미널이 한꺼번에 나와요. 설치 화면 그림은 없고 영어 이름을 글로만 안내해요. 이 분량 · 난이도가 알맞은지 제가 판단하기 어려워요. 선택지: ① 그대로 ② 필수(SETUP/0 ① ② ④ · SETUP/1 ① ③ · SETUP/2 ① ~ ⑤)와 선택 · 문제 해결을 시각적으로 나눔 ③ 설치 화면 그림을 넣음(Windows 설치 파일 첫 화면의 PATH 칸 등)
