## 3. 고치다 새로 찾은 것

- X14 `calculate` 의 주석 「`"1..2"` 처럼 점이 둘」 이 틀렸어요. 실제로 돌려 보니 `1..2` 는 에러가 아니라 그대로 돌아오고 `1..2+3` 에서 에러가 나요. 같은 글이 6곳에 복사돼 있어 모두 맞췄어요.
- L33/3 의 Pylance 경고 문장(QA 는 「의심」)을 pyright 로 검사하니 경고가 0개였어요. 실수로 보고 문장을 지웠어요.
- L15C 의 에러 문구가 QA 말보다 더 갈렸어요. 인자 없는 `raise X` 와 안이 `pass` 인 클래스에 메시지를 넘길 때 에러가 달라서, 본문에 둘 다 적었어요(실제로 돌려 확인).
- B8#5 의 마지막 문단에 요구가 일곱 가지 몰려 있었어요(보고서는 짚지 않음). 번호 목록으로 풀었어요.
- L8B 의 매개변수 `end` 를 `mark` 로 바꾸다가 X14 칩이 옛 이름으로 남았어요. 합칠 때 찾아서 맞췄어요(LESSON R14 에 기록).
- L18B 예제에 넣은 `print(list(map(lambda …)))` 가 `check_nesting`(괄호 3겹)에 걸려 두 줄로 나눴어요. 검사가 제 구실을 한 예예요.
