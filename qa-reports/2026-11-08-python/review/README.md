## 5. QA 방에 돌려줄 것

- 챕터 11 보고서의 「쪽 n」 은 1부터 센 번호였어요(「X14 쪽 7」 = `X14/6`). 4절의 `X16/2` · `X13/5` 도 같아서 실제로는 `X16/1` · `X13/4` 였어요. 보고서 0절 약속(0부터)과 달라요.
- 보고서와 판정이 갈린 곳(QA 오판 6 · 일부 부분 고침)의 까닭은 챕터 문서에 있어요. 예: X6 「이 레슨 7쪽」 은 화면 배지가 1부터 세서 맞았어요. X1 만들어 보기 2 「셋째 · 넷째 줄이 함정」 은 넷째 줄 `max(sums, key=int)` 가 점수가 아니라 키를 돌려주는 함정이라 원래 글이 맞았어요(힌트 한 줄만 더함).
