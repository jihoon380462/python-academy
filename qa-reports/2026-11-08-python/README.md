## 6. 고치는 순서 제안 (고치지 않음 · 사용자 판단)

1. **틀린 정보 3-A**(12건). 한두 줄씩이라 한 PR 로 가능. 2-5 의 「레슨 레슨」 10곳은 원문에서 링크 앞의 「레슨」 만 지우면 되고(`[[레슨:…]]` 가 이미 「레슨 N」 로 바뀜), 보스 레슨 링크 뒤의 「의 가계부」 같은 말도 같은 원리예요. 이 종류는 `check_book` 에 「`레슨 [[레슨:`」 패턴 검사를 넣으면 다시 안 생겨요.
2. **3-B 의 칩 · 안 배운 문법**. 칩 글자를 정답 모양에 맞추고, 빠진 한 줄을 본문에 넣기.
3. **폰 코드 블록 · 에러 상자 잘림(2-3: 458쪽 · 상자 1180개, 이 목록에서 영향이 가장 커요)**: 에러 · 경고 상자만이라도 줄바꿈 허용(`white-space: pre-wrap`), 코드 블록에는 「더 있음」 표시나 폰에서만 줄바꿈. `qa_screens.py` 에도 이 측정을 넣으면 같은 일이 다시 안 생겨요. 「만들어 보기」 쪽(최대 약 2만px)의 길이는 문제 카드 · 칩을 접어 두는 방식도 같이 따져 볼 만해요.
4. **자동 검사 보강**: 「정답이 쓰는 문법이 칩이 가리키는 쪽에 있는가」 를 `check_book` 에 추가(3-B 가 모두 이 종류). 쓰지 않는 칩 · 문제 번호 · 줄 수 말(「여섯 줄」 · 「네 문제」)과 실제 개수 비교도 후보.
5. **QA 지시서에 준비 단계** `pip install pytest playwright` 추가.
6. 한 쪽 과밀(3-C), 일관성(4절)은 다음 읽기 검수에서 쪽 단위로 정리. 「쪽을 더하거나 지우지 마요」(지시서 5절) 제약이 있어서 쪽을 나누려면 맨 끝에만 새 쪽을 붙이는 방식을 따져야 해요.

## 7. 다시 돌리는 법

```bash
pip install pytest playwright
node tools/check_book.mjs python
node tools/check_level.mjs --course python
python3 tools/qa_screens.py --w 390 --h 844 --out /tmp/qa_m python
```

읽기 검수에 쓴 본문 추출 스크립트와 2-3 의 전수 측정 스크립트는 저장소에 넣지 않았어요(임시 작업 폴더에만 있음). 전수 측정의 핵심은 `UI.go('lesson',{lessonId,page})` 로 모든 쪽을 열고 `.bk-art pre` 마다 `scrollWidth > clientWidth + 2` 를 세는 것이에요. 같은 일을 하려면 `content.js` 와 `book.js` 를 `vm` 으로 불러 `BOOK.pages[id/쪽].rep` 를 적용해 쪽 글을 뽑으면 돼요. 이 때 `<` `>` 를 태그로 지우지 않게 주의하세요.
